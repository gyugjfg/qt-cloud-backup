# 云备份项目素材清单

把截图放在本目录，把视频放在 Release 素材目录；文件名保持下面的英文命名，便于 HR 和 GitHub 页面理解。截图使用样例节点、样例文件名和脱敏地址，不要出现真实用户目录、IP、账号或密码。

## 截图顺序

| 文件名 | 画面内容 | 必须展示 |
| --- | --- | --- |
| `01-client-home.png` | 客户端主页/任务工作台 | 节点入口、上传/下载入口、任务列表区域 |
| `02-node-management.png` | 节点管理页 | 节点名称、地址、端口、在线状态；使用示例值 |
| `03-remote-directory.png` | 远程目录浏览 | 服务端目录、文件名、返回/进入目录和选择状态 |
| `04-upload-task.png` | 上传任务运行中 | 文件名、进度、速度、暂停/取消按钮和状态 |
| `05-download-resume.png` | 下载任务暂停/恢复或断点 | 暂停前后进度、恢复后的继续传输和最终状态 |
| `06-linux-server.png` | WSL/Linux 服务端终端 | 编译/启动命令、监听端口、服务端收到的协议日志 |

截图建议 1600x1000 或 1920x1080，PNG/JPEG 单张控制在 2 MB 左右。不要使用包含浏览器标签、桌面全屏、真实路径或个人通知的截图。

## 视频顺序

### `cloud-backup-upload-linux-e2e-demo.mp4`

建议 60-90 秒：

```text
00:00-00:08  WSL 启动服务端，展示专用存储根目录和监听端口
00:08-00:18  Windows 客户端打开节点管理，连接示例节点
00:18-00:32  浏览远程目录并选择待上传文件
00:32-00:52  创建上传任务，展示进度、速度和任务状态
00:52-01:05  WSL 终端展示服务端收到 fileput 并完成写入
01:05-01:20  客户端显示 Completed；可选展示文件大小或 SHA-256 对照
```

### `cloud-backup-download-resume-linux-e2e-demo.mp4`

建议 60-90 秒：

```text
00:00-00:10  客户端刷新远程目录并选择示例文件
00:10-00:28  创建下载任务，展示 Running 和进度变化
00:28-00:40  点击暂停，展示任务状态和已接收字节数
00:40-00:55  点击恢复，展示从已有偏移继续传输
00:55-01:08  WSL 终端展示 filesave/范围请求和服务端响应
01:08-01:20  客户端显示 Completed，展示本地文件落盘结果
```

只有真实复现客户端到 Linux 服务端的链路后，才能把视频标题写成 `e2e`。如果只能展示客户端或服务端单边画面，应改成 `client-demo` 或 `server-protocol-demo`，不要把单边画面描述成端到端完成。

## 录制前检查

- 使用临时演示目录和虚构节点，例如 `demo-node`、`127.0.0.1` 或 WSL 可达示例地址；
- 不展示 SSH 密钥、密码、云账号、真实 IP、用户目录或其他项目文件；
- 录制前清空无关任务和通知，确保客户端与服务端日志时间线连续；
- 上传/下载完成后至少保存一次文件大小或 SHA-256 结果，方便面试时解释验证边界；
- 录制完成后再把文件复制到本目录或 Release 素材目录，不把视频加入普通 Git 提交历史。
